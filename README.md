# 🚀 CivicFix

> **AI-Powered Smart Civic Complaint Management System**

CivicFix is a smart web-based platform that helps citizens report civic issues efficiently using Artificial Intelligence. The system analyzes uploaded images, assigns complaint priority, stores complaint data securely, and helps government authorities resolve issues faster.

---

## 📌 Version

**Current Version:** V1.0 (In Development)

---

## ✨ Features

- 📷 Upload complaint images
- 📍 GPS-based location detection
- 🤖 AI image damage analysis (Gemini API)
- ☁️ Cloud image storage (Cloudinary)
- 🗄️ Firebase Firestore database
- 📊 Authority Dashboard
- 📧 Email notifications
- 📱 Responsive user interface
